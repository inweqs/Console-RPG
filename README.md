# Console RPG 🎮

Консольная ролевая игра, разработанная для закрепления базового синтаксиса языка Java и ключевых концепций объектно-ориентированного программирования (ООП).

## 🚀 Реализованный функционал и архитектура

В проекте успешно применены и продемонстрированы следующие технологии:

- **Иерархия классов (Наследование):** Создан базовый класс `Character` и его специализированные наследники — `Warrior`, `Mage` и `Monster`.
- **Механика боя (Полиморфизм):** Реализована уникальная логика атаки и защиты для каждого игрового класса.
- **Безопасность данных (Инкапсуляция):** Настроена строгая валидация параметров, исключающая падение здоровья персонажей ниже нуля напрямую.
- **Игровой процесс (Game Loop):** Добавлен полноценный игровой цикл для непрерывного взаимодействия с пользователем.
- **Интерактивные действия:** Реализован метод исцеления персонажей во время или вне боя.

## 🛠 Технологический стек

* **Language:** Java (JDK 17+)
* **IDE:** IntelliJ IDEA
* **VCS:** Git / GitHub

## 📦 Как запустить проект

1. Клонируйте репозиторий:
   ```bash
     https://github.com/inweqs/Console-RPG.git
   ```
2. Откройте проект в **IntelliJ IDEA**.
3. Запустите главный класс (содержащий метод `main`).
